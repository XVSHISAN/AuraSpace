# 静界 · AuraSpace 工程级功能清单与质量审阅规范（QA Review & Release Gate）

> 本文档定义「静界 · AuraSpace」作为独立跨端工程（B站 Toy / Web / 后续 EXE & APK 打包底座）的**功能验收基准、审阅判定标准、缺陷分级与放行门禁**。每次发版前必须完成全部自动化与人工审阅项。

---

## 一、缺陷分级与放行门禁（Release Gate）

### 1. 缺陷分级标准
| 级别 | 定义 | 放行规则 |
| --- | --- | --- |
| **P0（阻断）** | 白屏崩溃、未捕获 JS 异常、音频完全无法播放/卡死、沉浸模式无法唤醒、核心持久化失效、违反平台安全/静态构建红线（如外链音频、自由文本 `<input type="text">`、SDK 轮询） | **一票否决，严禁构建发版** |
| **P1（严重）** | 功能逻辑偏差（如脑波频段显示错误、切场景误覆盖混音、倒计时卡顿/不刷新、关闭/渐弱尾音回弹、移动端溢出或遮挡） | **必须修复并通过回归测试后放行** |
| **P2（一般/体验优化）** | 非阻断型文案微调、动效节奏细节、边缘环境微瑕疵 | 记录待排期，不阻断当前版本 |

### 2. 四道发版门禁（全部 PASS 才允许打包发布）
1. **门禁 G1 — 静态与单元回归测试（`node --test tests/smoke.test.mjs`）**：11 项全部 `pass`，0 `fail`，`dist/` 产物语法经 `node --check` 校验通过。
2. **门禁 G2 — 无头 Chromium 真实浏览器 E2E 验收（`node tests/e2e.test.mjs`）**：覆盖 `F01–F11` 全量交互链及运行期网络/异常守卫（0 未捕获 JS 异常、0 外部音视频请求），全部 `[PASS]`，退出码为 `0`。
3. **门禁 G3 — 官方静态合规预检（`python scripts/toy_doctor.py`）**：分别对 `dist` 与 `release/auraspace-toy.zip` 校验，均须返回 `{"ok": true, "findings": []}`。
4. **门禁 G4 — 关键视觉产物人工核验**：检查生成的海报/预览截图（尤其是 `release/preview-card.png`、`release/preview-breath.png` 等），确认排版、对比度、居中与去水印/去引流文案要求无误。
